# Martian Map

An editorial-style interplanetary survival guide for the red planet. The landing page includes a responsive topographic map, clickable landing zones, field notes, mission stats, and a survival essentials checklist.

## Run locally

This is a dependency-free static site. Open `index.html` directly in a browser, or serve the folder with any static file server:

```bash
python3 -m http.server 8000
```
